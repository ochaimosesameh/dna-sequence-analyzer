# DNA Sequence Analyzer

**Author:** Ochai Moses Ameh

## About the Project
A beginner-friendly Python project for basic DNA sequence analysis.

## Features
- Accepts a DNA sequence.
- Converts sequences to uppercase.
- Removes unnecessary whitespace.
- Checks for invalid DNA bases.
- Calculates sequence length.
- Counts A, T, G, and C bases.
- Calculates GC content.
- Supports analysis of multiple sequences in FASTA format.

## Technologies Used
- Python
- FASTA format

## Purpose
This project demonstrates basic Python programming skills applied to bioinformatics.
